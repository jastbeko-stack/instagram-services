# منصة انستازون (InstaZone) لخدمات انستقرام
متجر بيع يوزرات وحسابات انستقرام وسيرفرات زيادة المتابعين والتفاعل مع دعم الدفع المشفر (USDT).

---

## 🌟 أبرز مميزات المنصة

1. **متجر يوزرات وحسابات انستقرام (Instagram Usernames Marketplace)**:
   - تصنيفات متعددة: يوزرات رباعية (4L)، شبه ثلاثية، قديمة 2012-2015، موثقة بالعلامة الزرقاء.
   - شراء فوري يخصم من رصيد المحفظة مع كشف بيانات الدخول والإيميل الأساسي (OGE) تلقائياً وآمناً للمشتري.
   - حماية الحسابات المباعة من التكرار بنظام القفل التلقائي.

2. **سيرفرات زيادة المتابعين والتفاعل (SMM Panel)**:
   - دعم **الربط التلقائي** مع سيرفرات ومزودي SMM عبر Standard API v2 (JustExpan, Peakerr, Secsers...).
   - دعم **التنفيذ اليدوي** للخدمات الخاصة أو عالية الدقة.
   - حاسبة تكلفة تفاعلية مباشرة تحسب السعر بالـ USDT بدقة لحظة بلحظة.
   - نظام متابعة حالات الطلبات بالوقت الفعلي.

3. **نظام المهام اليومية ونقاط المكافآت (Tasks & Earn Points)**:
   - مهام تفاعلية مخصصة (لايك على بوستات، لايك ومشاهدة ريلز، متابعة حسابات انستقرام، تعليقات، وتصويت ستوري).
   - احتساب النقاط اليومية لكل مهمة فور إنجازها.
   - **مكافأة إنجاز جميع المهمات اليومية (Streak Bonus)**: يحصل المستخدم على مكافأة كبرى (+100 نقطة إضافية) عند إكمال كافة مهمات اليوم.
   - **تحويل فوري للنقاط إلى رصيد محفظة**: استبدال النقاط برصيد USDT حقيقي (مثلاً: 1000 نقطة = 1.00 USDT) يمكن استخدامه مباشرة داخل المتجر.
   - لوحة تحكم كاملة للإدارة لإنشاء مهمات جديدة، تحديد الروابط والروابط المستهدفة، ومتابعة سجلات التحويل.

4. **المحفظة الرقمية والدفع المشفر (Crypto / USDT Wallet)**:
   - استقبال إيداعات USDT عبر شبكتي **TRC20** و **BEP20**.
   - كود QR ديناميكي لسهولة المسح من Binance أو TrustWallet ونسخ المحفظة بضغطة زر.
   - تدقيق واعتماد الإيداعات عبر كود المعاملة (TXID) بضغطة زر من لوحة الإدارة.
   - سجل محاسبي كامل لجميع الحركات المالية للمستخدم.

4. **لوحة تحكم إدارية متكاملة (Super Admin Dashboard)**:
   - إدارة كاملة لليوزرات، الخدمات، التصنيفات، والمزودين الخارجيين.
   - إدارة وقبول/رفض إيداعات الـ USDT.
   - إمكانية تعديل رصيد أي مستخدم يدوياً (إضافة أو خصم مع بيان السبب).
   - إمكانية إلغاء الطلبات مع ميزة الاسترجاع التلقائي للأموال إلى محفظة العميل.
   - التحكم بعناوين محافظ الإيداع وقنوات التواصل (تليجرام وواتساب).

## 🛠️ تشغيل المشروع محلياً

يمكنك تشغيل المشروع بالضغط المزدوج على ملف:
`run_project.bat`

أو عبر موجه الأوامر PowerShell:
```powershell
$env:PATH = "C:\xampp\php;" + $env:PATH
php artisan serve --port=8000
```
ثم فتح المتصفح على: `http://127.0.0.1:8000`
